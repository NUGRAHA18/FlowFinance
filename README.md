# FlowFinance

FlowFinance is a modern fintech-style personal finance management web application designed for students.

## Features

- Expense & income tracking
- Budget management
- Savings goals
- Debt tracking
- Subscription tracking
- Financial analytics dashboard

## Tech Stack

Frontend

- React
- Vite
- TailwindCSS

Backend

- Node.js
- Express.js

Database

- PostgreSQL
- Prisma ORM

Authentication

- JWT
- bcrypt
